MiMi Messenger v5.9.0

New:
- Delete chat for yourself from the Chats tab.
- Messages are NOT deleted from the database.
- The other participant keeps their history.
- If a new message arrives after a chat was hidden, the chat can reappear.
- Opening the person from People restores the chat to Chats.

Setup:
1. Run hidden_chats.sql in Supabase SQL Editor.
2. Replace app.js, index.html and style.css in GitHub Pages.
3. Wait for GitHub Pages to deploy.
4. Refresh the messenger.

No changes to E2EE message encryption or chat photo encryption.
